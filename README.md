## Deployment

Every push to `master` is built and deployed by [ShipYard](https://github.com/thakurdotdev/shipyard) to [thakur.dev](https://thakur.dev) (`www.thakur.dev` redirects there). The site is a Next.js static export served directly by Nginx.
